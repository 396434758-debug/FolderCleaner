# FolderCleaner

一个 Windows 文件夹清理小工具：统计所选目录下每个一级文件夹的大小和最后修改时间，手动勾选后整个移入回收站。适合清理 AppData 残留、游戏目录等。

## 功能

- 可添加多个扫描目录，支持从资源管理器拖入
- 递归统计文件夹大小、文件数和最后修改时间，只读取文件信息，不打开文件内容
- 按名称、路径、大小（大于／小于／等于）和“超过 X 个月没有修改”筛选
- 只移入回收站，拒绝永久删除，回收前重新核对文件夹是否有变化
- 系统目录、盘根、用户目录等位置只统计，不能勾选
- 不跟随符号链接和目录联接；路径超过 260 字符的文件夹可以扫描，但不能回收（回收站放不下）
- 可选的 AI 说明：把文件夹信息复制给你常用的 AI，再把结果导入，“说明”栏就会显示它属于哪个软件或游戏

软件本身不联网。AI 说明需要你手动粘贴，发送前可以预览全部内容；发送的是文件夹名、大小、修改时间、最外层的子文件夹名、文件类型统计和 exe 文件名，不包含文件内容。说明是 AI 的推测，可能有错，只用于显示和搜索，不影响勾选和回收。

## 下载

到 [Releases](../../releases) 下载 `FolderCleaner.zip`，解压后双击 `FolderCleaner.exe`。需要 Windows 10（1903 以后）或 Windows 11，无需安装。

程序没有数字签名，第一次打开时 Windows 可能提示“Windows 已保护你的电脑”，点“更多信息”再点“仍要运行”即可。

## 使用前请注意

清理前请先退出相关程序，并逐条核对路径。AppData 里同时有配置、账号状态和存档，软件不会判断哪些可以删。回收后可在系统回收站还原，确认无误前不要清空回收站。

完整说明见 [使用说明.md](使用说明.md)。

## 从源码编译

不需要安装 Visual Studio，使用 Windows 自带的 .NET Framework 编译器：

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

运行自测（只使用临时目录里新建的测试文件夹，其中几个会真实进入系统回收站）：

```bash
FolderCleaner.exe --self-test
```
